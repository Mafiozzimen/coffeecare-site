# ПРОШИВКИ КОФЕМАШИН (обновления ПО)
# COFFEE CARE


## De'Longhi — v1.8.2 (2025)
Модели: ECAM 22.110,Magnifica S,PrimaDonna
Источник: Официальный сайт De'Longhi → Поддержка → Обновление ПО (USB)
Заметки: Обновление через USB. Перед прошивкой сделать бэкап настроек. При сбое — восстановление через сервисный режим: удерживать кнопку OK 15 сек при включении.

## Jura — v2.4.1 (2025)
Модели: E8,Z10,GIGA X3c
Источник: Jura Support → Downloads → Firmware Update (Wi-Fi/приложение J.O.E.)
Заметки: Обновление по Wi-Fi через приложение J.O.E. или по USB. Требуется аккаунт Jura. После обновления перекалибровать помол и проверить блок.

## La Marzocco — M1 v4.6 / v4.7
Модели: Linea PB,GS3,Strada
Источник: La Marzocco Home App (GS3/Linea Mini) + официальный портал
Заметки: GS3/Linea Mini: обновление через приложение по Wi-Fi. Linea PB: замена плат/чипов только сервисным инженером.

## Melitta — v2.1.0
Модели: CI Touch,Passione OT
Источник: Melitta Service Partner Portal
Заметки: Только через авторизованный сервис. Прошивка чипа на плате. После — сброс к заводским и калибровка.

## Nivona — v1.2.8
