📡 Прошивки и обновления кофемашин

Полное руководство: как обновить ПО вашей кофемашины, где взять прошивку, что важно знать. Обновление прошивки исправляет ошибки, добавляет новые рецепты и функции.

☕ Jura

Актуальные версии: E8 v2.4.1 · Z10 v2.4.1 · GIGA X3c v2.4.1

Способы обновления

  1. Через приложение J.O.E. (Wi-Fi): подключите машину к Wi-Fi (2.4 GHz), откройте приложение J.O.E., машина сама предложит обновление.
  2. Через USB: скачайте файл прошивки на сайте Jura (Support → Downloads), скопируйте на USB-флешку (FAT32), вставьте в USB-порт машины, следуйте подсказкам на дисплее.
  3. Требуется аккаунт Jura и регистрация машины.
💡 После обновления: сбросьте фильтр Claris в меню и перекалибруйте помол — машина «забудет» настройки.
⚠️ НЕ отключайте питание во время прошивки! Это может убить плату. Прошивка занимает 5–15 минут.

🔧 De'Longhi

ECAM 22.110 v1.8.2 · Magnifica S v1.8.2 · PrimaDonna v1.8.2

Способы обновления

  1. Через USB: на сайте De'Longhi (Поддержка → Обновление ПО) скачайте архив, распакуйте на USB-флешку (FAT32, файл в корне).
  2. Выключите машину, вставьте USB, включите — начнётся обновление.
  3. Для моделей с Wi-Fi/приложением Coffee Link — обновление через приложение.
⚠️ Перед прошивкой сделайте бэкап настроек (если модель поддерживает). При сбое — сервисный режим: удерживайте кнопку OK 15 сек при включении.

🟡 Saeco / Philips

Xelsis v1.6.0 · 2200/3200/4300 v1.4.3

Способы обновления

  1. Philips (2200–4300): приложение Philips Coffee — машина с Wi-Fi сама скачивает обновление.
  2. Saeco Xelsis: через Bluetooth-приложение (модели с модулем) или USB-кабель к компьютеру.
  3. Старые Saeco: только через сервисный USB-адаптер (требует доступ к ПО производителя).
💡 Проверьте текущую версию: меню → Настройки → Информация → Версия ПО.

⚪ Krups / Bosch / Siemens

Krups EA810 · Bosch VeroCafe · Siemens EQ

Способы обновления

  1. Home Connect (Bosch/Siemens): приложение Home Connect → выберите машину → Обновление ПО.
  2. Krups: модели с Wi-Fi обновляются через приложение Krups / Home Connect. Без Wi-Fi — только в сервисе.
⚠️ Если ваша модель без Wi-Fi и без USB — обновление прошивки возможно только через сервисный центр (замена чипа/платы).

🌱 Melitta / Nivona

Melitta CI Touch · Nivona CafeRomatica

Способы обновления

  1. Melitta: только через авторизованный сервис — прошивка чипа на плате программатором.
  2. Nivona: через сервисный USB-адаптер, доступ нужен партнёрам Nivona.
💡 Эти бренды не дают пользовательских прошивок — «самому» обновить нельзя. Обратитесь к нам — сделаем за 1 день.

🏢 Профессиональные (La Marzocco, Nuova Simonelli, Rancilio)

La Marzocco GS3/Linea Mini v4.6 · Mythos DSP v5.2

Способы обновления

  1. La Marzocco GS3 / Linea Mini: через приложение La Marzocco Home App по Wi-Fi.
  2. Linea PB / Strada: только сервисным инженером (замена плат с прошивкой).
  3. Nuova Simonelli Mythos: прошивка DSP-платы через компьютер с фирменным ПО.

🏪 Вендинговые автоматы (Unicum, Saeco Vending, Necta, Jofemar)

Unicum W20 v3.2 · Saeco Vending v7.1

Способы обновления

  1. Unicum: прошивка через USB на плате управления. Сохраните конфигурацию дозаторов ДО обновления.
  2. Saeco Vending (Evoca): через SD-карту, загрузка из сервисного меню. После — проверьте телеметрию.
  3. Jofemar / Necta / Jetinno: через сервисный порт или SD-карту, инструкция в техпортале производителя.
⚠️ Для вендинговых автоматов прошивка критична: неверная версия может заблокировать платёжную систему. Доверяйте это специалистам.
